## 二、功能特性

### 2.1 信息采集
- **RSS订阅**：支持标准RSS/Atom Feed自动解析
- **网页轮询**：对无RSS的网站（如政府网站）定时抓取页面变化
- **双通道解析**：rss2json.com（主）+ 本地DOMParser（备），确保RSS解析成功率
- **CORS代理**：自动通过代理访问跨域资源（corsproxy.io / allorigins.win）
- **合规过滤**：默认开启中国大陆合规检查，屏蔽30+敏感境外域名

### 2.2 数据处理
- **关键字相关性过滤**：基于标题与关键字库的匹配度，过滤无关内容
- **智能去重**：批次内去重 + 与已有条目去重，避免重复内容
- **告警关键字**：重要/风险事件自动标记，支持浏览器桌面通知
- **自动采集**：页面打开自动运行，支持自定义间隔定时刷新

### 2.3 AI智能分析
- **多服务商支持**：智谱GLM / DeepSeek / Google Gemini / OpenAI兼容 / 自定义URL
- **可自定义Prompt**：摘要提示词、去重提示词均可编辑
- **单条AI摘要**：任意监控条目可一键生成AI摘要
- **AI连接测试**：一键验证API配置是否正确
- **预填测试Key**：首次使用无需额外配置即可体验AI功能

### 2.4 数据可视化
- **仪表盘**：统计卡片（活跃源/今日新增/重要告警/未读数）
- **饼图**：信息分类分布
- **柱状图**：各信息源采集量排行
- **折线图**：近7日采集趋势
- **关键字词云**：关键字出现频率可视化

### 2.5 报告生成
- **日报/周报**：自动汇总时间范围内的监控数据
- **AI摘要**：可选AI生成行业分析摘要
- **出版物风格PDF**：含封面页、统计概览、关键字热度、分类明细表格、信息源统计
- **TXT导出**：纯文本报告下载
- **CSV导出**：监控数据导出为CSV（UTF-8 BOM，Excel兼容）

### 2.6 设置管理
- **JSON导入/导出**：一键备份/恢复全部配置
- **深色模式**：全局主题切换
- **合规检查开关**：可关闭合规过滤（默认开启）
- **自动刷新配置**：间隔时间、开关
- **浏览器通知**：告警推送桌面通知
- **最大保留条数**：控制localStorage存储量

## 三、使用指南

### 3.1 快速开始

1. **打开首页**：在浏览器中打开 `index.html`
2. **自动采集**：首页打开1秒后自动运行监控（或点击右上角🔄按钮手动刷新）
3. **进入子系统**：点击任一板块卡片进入详细监控页
4. **查看数据**：子系统仪表盘展示统计数据和图表
5. **生成报告**：切换到"报告"标签页，点击"生成日报"或"生成周报"

### 3.2 信息源管理

1. 进入子系统页面，切换到"信息源"标签
2. **添加信息源**：
   - 名称：信息源的显示名称
   - URL：RSS地址或网页URL
   - 类型：RSS（自动解析Feed）或 页面轮询（检测网页变化）
   - 分类：自定义分类标签
3. **启用/停用**：通过开关控制
4. **删除**：点击删除按钮移除
5. **批量导入/导出**：支持JSON格式

### 3.3 关键字管理

1. 切换到"关键字"标签
2. **监控关键字**：用于内容过滤和关键词高亮
3. **告警关键字**：匹配时自动标记为重要/告警，触发浏览器通知
4. 点击关键字标签可删除

### 3.4 AI功能使用

1. 点击右上角⚙️打开设置
2. **选择AI服务商**（默认智谱GLM）
3. **API Key**：已预填测试Key，可替换为自己的Key
4. **自定义Prompt**：可编辑摘要和去重提示词
5. **测试连接**：点击"测试连接"验证配置
6. **使用AI**：
   - 报告页勾选"AI摘要"后生成报告
   - 时间线条目点击"AI摘要"按钮

### 3.5 报告与导出

1. 切换到"报告"标签
2. 选择日期、报告类型（日报/周报）
3. 点击"生成日报"或"生成周报"
4. 报告生成后可：
   - **生成PDF报告**：打开新窗口，可打印为PDF
   - **复制文本**：复制到剪贴板
   - **下载TXT**：保存为文本文件
   - **导出CSV**：数据导出为Excel兼容格式

### 3.6 设置与数据

- **导出全部系统**：首页设置中导出所有子系统的配置（JSON）
- **导入全部系统**：从JSON文件恢复配置
- **导出数据**：子系统设置中导出当前监控数据（CSV）
- **清空数据**：删除当前子系统所有数据（慎用）

## 四、部署方式

### 方式一：本地打开
直接在浏览器中打开 `index.html` 即可使用，无需服务器。

### 方式二：GitHub Pages
1. 将所有文件推送到GitHub仓库
2. 在仓库Settings → Pages中选择分支
3. 访问 `https://{username}.github.io/{repo}/`

**注意事项**：
- 需在仓库根目录添加 `.nojekyll` 文件（避免Jekyll处理）
- 部署后CDN缓存需1-2分钟生效

### 方式三：Cloudflare Workers
1. 将所有文件打包为zip
2. 上传到Cloudflare Workers Sites
3. 配置自定义域名

## 八、合规过滤说明

系统默认开启合规检查，屏蔽以下类型的境外域名：

- 新闻媒体：大纪元、RFI、德国之声、BBC、纽约时报、华盛顿邮报、华尔街日报等
- 通讯社：路透社、AP、Bloomberg等
- 社区网站：文学城、留园网、万维读者等
- 组织网站：Amnesty、HRW等
- 其他：中国数字时代、盲眼猫等

可在设置中关闭合规检查（不推荐在中国大陆使用时关闭）。

## 九、数据存储

- **存储方式**：浏览器 localStorage
- **Key格式**：`mon_{系统ID}_{类型}`（如 `mon_chaowan_items`）
- **容量限制**：5MB（建议maxItems不超过1000）
- **数据安全**：所有数据仅存储在浏览器本地，不上传任何服务器
- **API Key**：明文存储在localStorage，注意安全

## 十、常见问题

### Q: 为什么有些信息源采集失败？
A: 可能原因：
1. 网站限制CORS访问（代理也无法绕过）
2. 网站使用JS动态渲染（fetch拿不到内容）
3. 网站暂时不可用或被封
4. 代理服务超时（默认15秒）

### Q: 为什么AI摘要失败？
A: 可能原因：
1. API Key无效或过期
2. 网络无法访问API服务（需科学上网）
3. 请求频率过高触发限流
4. Prompt过长被截断

### Q: 如何在不同电脑间同步设置？
A: 使用JSON导出/导入功能：首页设置 → 导出全部系统(JSON) → 在另一台电脑导入。

### Q: 数据太多localStorage满了怎么办？
A: 减小"最大保留条数"设置，或手动清空数据。后续版本将支持IndexedDB存储。

### Q: PDF报告打印时排版不对？
A: 打印时选择"A4"纸张大小，取消"页眉页脚"选项，边距设为"默认"。
